# TIBasicM0
When I was a teenager, I enjoyed to program on my TI-84. I remember programming a binary to base-10 converter for my computer science class as one of my projects. Today, I am working on a compiler that generates assembly for the Cortex-M0 Microcontroller from a Ti-84 Basic-inspired language. While unpractical I hope to gain valuable knowledge about the Cortex-M0 chip, and understand how compilers work on a deeper level.
